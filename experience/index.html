MWR CyberSec Virtual Internship

Web application security · MWR CyberSec · Jul 2026

An eight-week program run by MWR CyberSec, a South African security consultancy, focused on attacking and securing web applications. I worked through authentication attacks (user enumeration, brute forcing and JWT "alg: none" forgery), cross-site scripting, CORS and DOM-based attacks, CSRF, and SQL injection, including union-based, blind, second-order and out-of-band variants. I also exploited file upload filters by bypassing MIME type, extension and magic-byte checks.

Along the way I used standard tools for recon and exploitation (Nmap, Gobuster, Hydra, Enum4linux), privilege escalation (LinPEAS) and password cracking (John the Ripper, Hashcat), and I wrote up findings in a professional security report.
